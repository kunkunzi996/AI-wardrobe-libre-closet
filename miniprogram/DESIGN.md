# 小程序前端设计规范 · 方案 B 柔彩卡片

> 这份文档把「方案 B 柔彩卡片」设计稿浓缩成可复用的规范。
> 新加页面 / 改样式时照着这里抄数值，就能和现有页面保持统一。
> 所有数值都和 `miniprogram/` 里实际用的一致；单位默认 `rpx`（1px ≈ 2rpx）。

---

## 一句话风格

柔和时尚紫 `#6F5AE0` 主色 · Inter / PingFang SC 字体 · 12–18px 圆角卡片 ·
按分类轮换 5 种柔彩底色（薰衣草 / 蜜桃 / 薄荷 / 天蓝 / 玫瑰）·
AI 识别用 Notion「醒目黄」`#F3E08A`。

## 1. 颜色

### 主色 / 文字 / 背景

| 用途 | 色值 | 说明 |
|---|---|---|
| 主色（按钮 / 高亮 / 选中） | `#6F5AE0` | 柔和紫，全站主 CTA |
| 主色-深（按钮文字 / 强调） | `#5A47C9` | 次级强调、白底上的紫字 |
| 页面背景 | `#ECEAF0` | 淡紫灰 |
| 卡片 / 表单背景 | `#FFFFFF` / `#F7F6FB` | 白卡 / 浅紫填充（输入框） |
| 主文字 | `#221C3A` | 标题、正文 |
| 次文字 | `#6B6580` | 说明、字段标签 |
| 弱文字 | `#9A94AC` | 计数、占位、meta |
| 失效 / 图标灰 | `#B4AEC4` | 未选中标签栏图标 |
| 删除 / 危险 | `#C0392B` | 删除按钮文字、删除确认色 |

### 柔彩分类色（5 色轮换）

每种柔彩有「底色」和配套的「深色文字」。卡片用底色，卡片内文字用深色。

| 名称 | 底色 | 配套深文字 | 用在哪个分类 |
|---|---|---|---|
| 薰衣草 lavender | `#E1D9F6` | `#5A47C9` | 上衣 tops |
| 蜜桃 peach | `#FBE1C9` | `#B5651F` | 下装 bottoms |
| 薄荷 mint | `#D4EEDD` | `#2C8559` | 外套 outerwear |
| 天蓝 sky | `#D9E7FB` | `#5F77A6` | 鞋子 / 包包 footwear、bags |
| 玫瑰 rose | `#F9D6E6` | `#B23A78` | 连衣裙 / 配饰 dresses、accessories |

> 底色比设计稿原值（薰衣草 `#ECE8FB` 等）略加深，便于在真实照片旁看清色块。
> 提示 / 错误等「通知背景」仍用更浅的原值（如错误提示 `#FBE6F0`），不要和衣物色块混用。

> 全局 class 已在 `app.wxss` 定义：`.tint-lavender / .tint-peach / .tint-mint / .tint-sky / .tint-rose`，直接复用。

### AI / 语义色

| 用途 | 底色 | 文字 |
|---|---|---|
| AI 识别建议面板（Notion 醒目黄） | `#F3E08A` | `#6B5310` |
| 错误提示 | `#FBE6F0` | `#B23A78` |

## 5. 组件规范

### 主按钮（紫色 CTA）
底色 `#6F5AE0`，白字，字号 30rpx / 600，高 92–96rpx，圆角 20rpx，带紫色按钮阴影。
小程序记得清掉默认描边：`button::after { border: none }`。

### 次按钮（白底）
白底，文字用 `#5A47C9` 或 `#221C3A`，圆角 18rpx，卡片浅阴影。
描边款用 `::after { border: 2rpx solid #E4E1EE }`。

### 危险按钮（删除）
白底，文字 `#C0392B`，无背景色。`wx.showModal` 的 `confirmColor` 用 `#c0392b`。

### 柔彩衣物卡
外层 padding 20rpx、圆角 24–32rpx、按分类套 `.tint-*` 底色；
内部照片区圆角 16–20rpx、底色 `rgba(255,255,255,0.55)`；
名称 28rpx/600 `#2E2742`，meta `rgba(46,39,66,0.55)`。

### AI 识别面板（Notion 黄）
底色 `#F3E08A`，标题前缀 `✨`、文字 `#6B5310`/700；
内部标签用 `rgba(255,255,255,0.7)` 白片 + `#6B5310` 文字。

### 筛选 pill
白底 / 文字 `#5A47C9`，圆角 999rpx；选中态底色翻成主色 `#6F5AE0` + 白字。

### 2×2 属性格（详情页）
四个柔彩小卡（peach / mint / sky / rose），每个：小标签（配套深文字、22rpx）+ 大值（30rpx/600）。

### 今日 AI 推荐横幅
主色 `#6F5AE0` 底、白字，圆角 36rpx，右上角散落 3 个彩点（粉 `#FBCFE0` / 黄 `#FCE38A` / 绿 `#9FE8C4`），底部白色「查看搭配」小按钮。

### 底部标签栏（自定义）
固定底部，白色半透明 + 顶部 1rpx 描边 + 毛玻璃；高 110rpx + `env(safe-area-inset-bottom)`；
图标用 CSS 画形状（衣橱=方块 / 搭配=菱形 / 今日=圆形），选中 `#6F5AE0`、未选 `#B4AEC4`。
组件在 `miniprogram/custom-tab-bar/`。

## 6. 分类 → 柔彩对照（落地约定）

衣物卡按 `category` 字段自动套色，映射在 `pages/wardrobe/index.js` 的 `categoryTintMap`：

```
tops 上衣        → tint-lavender 薰衣草
bottoms 下装     → tint-peach    蜜桃
outerwear 外套   → tint-mint     薄荷
footwear 鞋 / bags 包 → tint-sky  天蓝
dresses 裙 / accessories 配饰 → tint-rose 玫瑰
other 其他       → tint-lavender 薰衣草（兜底）
```

## 7. 页面布局套路

- 页面：背景 `#ECEAF0`，内边距 `24rpx 32rpx`；含底部标签栏的页面底部留 `160rpx`（衣橱网格留 `220rpx`）避免被遮挡。
- 顶部：左侧大标题 + 弱文字副标题，右侧一个白色圆角小图标 / 按钮。
- tab 页之间跳转用 `wx.switchTab`；非 tab 页（表单 / 详情）用 `wx.navigateTo`。
- tab 页不能带参数：需要传值（如「围绕这件搭配」的核心衣物 id）走 `getApp().globalData` 中转。

---

## 8. Do / Don't

**Do**
- 主 CTA 统一用紫色 `#6F5AE0` 圆角矩形按钮。
- 衣物 / 属性卡按分类轮换 5 种柔彩，保持活泼一致。
- AI 相关信息统一用 Notion 黄 `#F3E08A`。
- 卡片 12–18px 圆角、轻阴影，背景留淡紫灰。

**Don't**
- 别把主按钮做成胶囊形（圆角矩形才对）。
- 别用紫色当大面积背景或正文颜色。
- 别在一个页面混进旧的墨绿 / 暖棕配色。
- 柔彩卡里别用纯黑字，用对应的「深文字」色。
