# 没有指定核心时先筛候选衣橱再组套

用户未指定核心衣物时，系统不得自行指定默认核心。先按穿搭情境排除明显不适用的衣物（明确冷热冲突，以及用户明确说出的颜色、厚薄硬性需求），再由 AI 从候选衣橱完成组合与解释；本地规则负责硬筛，不把「能不能穿」交给模型。

有核心时仍围着该件；核心豁免天气硬排除，也豁免硬性需求和排除品类（只约束其余衣服）。核心和需求打架时必须提醒，不能闷声出套，也不撤换核心。没有核心时，说出多个颜色则候选保留这些颜色（红或黑都留）；「只要黑色」才只留黑。放弃「从合格池再锁一件当核心」：那仍是默认核心，三套会再次长得像同一件换配饰。AI 不可用时不出本地套，见 ADR 0008。两套是否重复只看衣物 ID 集合，不看标签是否相同。
