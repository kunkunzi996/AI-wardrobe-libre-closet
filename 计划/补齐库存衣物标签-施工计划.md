## 1. 背景（为什么做）

昆昆子的老婆账号里有 100+ 件衣服，都是在"12 组标签库"上线**之前**录入的，很多衣物的标签是空的或残缺的。

项目里其实已经有一个现成的 AI 识图服务 `GarmentVisionService.analyzeImage(fileName)`——**能对着已存好的照片，识别出严格限定在标签库内的完整 12 组标签**。本次要做的，就是把这个能力批量地用到存量衣物上，把缺的标签补齐。

## 2. 现状（已确认的关键事实）

- 识图服务：`src/ai/garment-vision.service.ts`，`analyzeImage(fileName)` 读已存照片 → 返回 `GarmentVisionResult`（含完整 `taxonomyTags` + 扁平字段 color/seasons/styleTags/sceneTags/material/thickness/fit/subcategory）。识别模型：通义千问 `qwen3.7-plus`（可用 `QWEN_VISION_MODEL` 覆盖）。
- 衣物实体：`src/dal/entity/garment.entity.ts`，已有 `taxonomyTags`（JSON）+ 扁平镜像字段。**注意：当前 AI 搭配读的是扁平字段（seasons/styleTags/sceneTags/color），所以补标要两边都补。**
- 后台骨架：`src/wardrobe/miniapp-admin.service.ts` + `miniapp-admin.controller.ts` 已有"按用户查库存/导出 Excel"，本次在同处新增"批量补标签"。DI 上 `WardrobeModule` 已 import `AiModule`，`GarmentVisionService` 可直接注入（`MiniappWardrobeController` 已在用）。
- 小程序后台页：`miniprogram/pages/admin-inventory/`（已有用户列表 + 导出按钮）。
- 迁移：项目同时维护 `postgres` 和 `sqlite` 两套迁移，手写风格见 `Migration20260711000100.ts`。

## 3. 已确认的产品决策

1. **只补空缺，绝不覆盖**已有标签/已填字段。
2. **批量自动填完即可**，不逐件人工确认；老婆事后浏览时随手改。
3. **没照片的衣物**：AI 补不了，单独统计并返回清单，交给用户手动。
4. **范围**：先只针对指定用户（她的账号）手动触发，不做全站自动/定时。
5. **触发方式**：后台加按钮，**分批跑**（点一次处理一批，显示"已补/还剩"，点到完成）。

## 4. 本次范围 / 不做什么

**做**：新增"按用户批量补标签"的后端接口 + 小程序后台按钮；新增一个 `tagsBackfilledAt` 标记列用于进度与断点续跑。

**本次不做**（都留到后续计划）：
- ❌ 不改 AI 搭配逻辑（喂全标签、温度规则引擎、好看规则）——那是下一份计划。
- ❌ 不换/不升级识别模型。
- ❌ 不批量填 `pocket*` / `chestMark*` 等结构字段（只补"标签类"字段）。
- ❌ 不做自动/定时补全。
- ❌ 不动 `category`（必填、已存在，保持不变）。

## 5. 关键技术点

1. **新增标记列 `tagsBackfilledAt`（Date, nullable）**：用来判断"这件是否已被 AI 处理过"，从而让"还剩 Y 件"计数准确、并支持断点续跑（不会无限重复处理同一件）。
2. **只补空缺的合并逻辑**：逐字段判断"当前为空才填"，12 组标签逐组合并。
3. **分批 + 每件落库**：每处理一件就 `flush` 一次，任一批中途断了也不丢进度。
4. **AI 不可用的保护**：若识别结果为空且 `confidence===0`（典型是没配 `QWEN_API_KEY`），**不打标记**、计入 `unreadable`，避免把整批衣物"烧成已处理却零标签"。

**3d. 新增方法**（放在 `findUserGarments` 后面；`assertAdmin` 已存在，直接复用）：

```ts
  private readonly BACKFILL_LIMIT_DEFAULT = 10;
  private readonly BACKFILL_LIMIT_MAX = 30;

  async backfillUserGarmentTags(
    adminUserId: number | undefined,
    targetUserId: number,
    limit?: number,
  ): Promise<BackfillTagsResult> {
    await this.assertAdmin(adminUserId); // 安全要点：管理员校验必须在最前
    const user = await this.userRepository.findOne(targetUserId);
    if (!user) throw new NotFoundException('用户不存在');

    const batchSize = Math.min(
      Math.max(1, Number(limit) || this.BACKFILL_LIMIT_DEFAULT),
      this.BACKFILL_LIMIT_MAX,
    );

    const garments = await this.garmentRepository.find(
      { owner: { id: targetUserId } },
      { populate: ['photo'], orderBy: { id: 'ASC' } },
    );

    const total = garments.length;
    const noPhoto = garments.filter((g) => !g.photo?.fileName);
    const pending = garments.filter(
      (g) => g.photo?.fileName && g.tagsBackfilledAt == null,
    );

    const em = this.garmentRepository.getEntityManager();
    let filledCount = 0;
    let unreadableCount = 0;
    const failed: Array<{ id: number; error: string }> = [];

    for (const garment of pending.slice(0, batchSize)) {
      try {
        const vision = await this.garmentVisionService.analyzeImage(
          garment.photo!.fileName,
        );
        const changed = this.mergeMissingTags(garment, vision);
        // AI 真正给出结果（补到了 或 置信度>0）才打标记；
        // 否则（多为未配 AI Key 的空 fallback）不打标记，留待重试
        if (changed || vision.confidence > 0) {
          garment.tagsBackfilledAt = new Date();
          await em.flush(); // 每件落库，中断可续
          if (changed) filledCount += 1;
        } else {
          unreadableCount += 1;
        }
      } catch (error) {
        failed.push({
          id: garment.id,
          error: error instanceof Error ? error.message : String(error),
        });
      }
    }

    const remaining = garments.filter(
      (g) => g.photo?.fileName && g.tagsBackfilledAt == null,
    ).length;

    return {
      total,
      withPhoto: total - noPhoto.length,
      processedThisRun: Math.min(pending.length, batchSize),
      filledCount,
      unreadableCount,
      noPhotoCount: noPhoto.length,
      noPhotoSamples: noPhoto.slice(0, 20).map((g) => ({
        id: g.id,
        name: g.name ?? '',
      })),
      remaining,
      failed,
    };
  }

  /** 只补空缺：当前字段为空且 AI 有值才写入；返回是否有改动 */
  private mergeMissingTags(
    garment: Garment,
    vision: GarmentVisionResult,
  ): boolean {
    let changed = false;

    // 1) 12 组分类标签：逐组补空
    const current = { ...(garment.taxonomyTags ?? {}) };
    for (const group of Object.keys(GARMENT_TAG_TAXONOMY) as GarmentTagGroup[]) {
      const existing = current[group];
      const incoming = vision.taxonomyTags[group];
      if ((!existing || existing.length === 0) && incoming && incoming.length) {
        current[group] = incoming;
        changed = true;
      }
    }
    if (changed) garment.taxonomyTags = current;

    // 2) 扁平镜像字段：仅当当前为空才补（当前 AI 搭配读的是这些）
    if (!garment.color && vision.color) {
      garment.color = vision.color;
      changed = true;
    }
    if (this.isEmptyArray(garment.seasons) && vision.seasons.length) {
      garment.seasons = vision.seasons;
      changed = true;
    }
    if (this.isEmptyArray(garment.styleTags) && vision.styleTags.length) {
      garment.styleTags = vision.styleTags;
      changed = true;
    }
    if (this.isEmptyArray(garment.sceneTags) && vision.sceneTags.length) {
      garment.sceneTags = vision.sceneTags;
      changed = true;
    }
    if (!garment.material && vision.material) {
      garment.material = vision.material;
      changed = true;
    }
    if (!garment.thickness && vision.thickness) {
      garment.thickness = vision.thickness;
      changed = true;
    }
    if (!garment.fit && vision.fit) {
      garment.fit = vision.fit;
      changed = true;
    }
    if (!garment.subcategory && vision.subcategory) {
      garment.subcategory = vision.subcategory;
      changed = true;
    }

    return changed; // 注意：绝不改 garment.category
  }

  private isEmptyArray(v?: string[]): boolean {
    return !v || v.length === 0;
  }
```

> 复用提示：`assertAdmin` / `userRepository` / `garmentRepository` 都已在本类里，直接用。
> 安全要点：① `assertAdmin` 放最前；② 只读空补空、**category 不动**；③ 每件 `flush`。

    const userId = Number(event.currentTarget.dataset.id);
    if (!userId || this.data.backfillingUserId) return;

    const page = this;
    page.setData({ backfillingUserId: userId });

      .catch(function (error) {
        wx.showToast({ title: error.message || 'AI补标签失败', icon: 'none' });

      .finally(function () {
        page.setData({ backfillingUserId: null });
      });
  },
